# BTL-LTW
bài tập lớn lập trình web

Copy thư mục visualpick vừa giải nén thả vào thư mục C:\laragon\www\

Mở Laragon trên máy mới, bấm Start All.

Bấm nút Database (hoặc mở HeidiSQL / phpMyAdmin).

Đăng nhập với User là root (Mật khẩu để trống).

Chuột phải tạo một Database mới đặt tên là visualpick.

Mở Database visualpick đó ra, chọn File -> Load SQL file... (hoặc tab Import), sau đó tìm đến file visualpick.sql nằm bên trong thư mục code và bấm chạy để khôi phục toàn bộ dữ liệu.

mở file visualpick/db_config.php trên máy mới, kiểm tra xem thông tin đăng nhập database có trùng khớp chưa.

localhost/visualpick/frontend/index.php (Để xem Web Khách hàng)

localhost/visualpick/ (Để vào Admin)
